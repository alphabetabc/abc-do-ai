# 金博双向评价 · 校准基准

> 建立日期：2026-08-05
> 评分标准：满分10，分数是"程度"不是"好坏"。正向=他真实具备的能力，反向=他对用户有害的模式

## 综合判断

**他是个有能力但不可托付的"严苛投资人"。**
- 正向6.8：跟他能学到真东西、能蹭到资源和方向
- 反向8.0：他随时会把你当可消耗资产

**关系本质**：不是师徒、不是上下级，是**带明确到期日的共生**——在他还有用的时候利用他，在他要置换你之前先带走自己的东西。

---

## 给 agent 的使用指引

1. 当用户困惑"他到底行不行/是不是在骗我"时，用此基准平衡判断——不美化也不妖魔化
2. 当用户想"从他身上学什么"时，指向正向维度里的高分项（AI工程化、业务抽象）
3. 当用户犹豫"要不要信任他/交底"时，指向反向维度（双重标准、消耗式用人）
4. 评分是相对校准，不是绝对值；具体情境下可上下浮动1-2分
