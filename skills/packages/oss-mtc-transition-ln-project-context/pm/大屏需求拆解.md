# 辽宁省军转厅国产化改造项目 - 大屏需求拆解

## 一、整体说明

- **大屏位置**：2.3 可视化分析 → 大数据综合展示
- **地图能力**：辽宁省行政区划地图，支持两级下钻
    - 第一级：展示各地市数据（cantType=4）
    - 第二级：点击地市下钻到区县（cantType=6），区县不再下钻
    - 其他模块数据随地图下钻联动切换
- **数据合并规则**：沈抚新区（编号2115）数据合并到抚顺市（编号2104）
- **导航切换**：4个大屏之间通过导航按钮切换（人员信息、辽宁信访信息、进京信访信息、信访数据比对）

## 七、公共参数说明

| 参数          | 含义                   | 取值                                       |
| ------------- | ---------------------- | ------------------------------------------ |
| cantCode      | 行政区域编号           | 省=21，地市/区县传对应编号                 |
| cantType      | 行政区域类型           | 4=地市级，6=区县级                         |
| ORGANID       | 行政区域编号（信访用） | 展示哪个区域传对应编号                     |
| REG_AUTHORITY | 登记机构               | 1=进京，2=本地，0=未添加                   |
| ACCEPT_SOURCE | 信访形式               | 1=网上信访，2=来访，3=来信，7=特殊人员信访 |

---

## 八、总结

- **共4个大屏**，总计 **24个展示模块**（每个大屏6个模块）
- 大屏2和大屏3结构完全一致，仅 `REG_AUTHORITY` 参数不同（本地=2 / 进京=1）
- 大屏4为对比大屏，在前两者基础上做本地vs进京的数据对比
- 涉及 **8张数据表**，信访相关6张（LETTER_SCREEN_1~6）+ 人员相关2张
- 所有信访模块通过 `REG_AUTHORITY`、`ORGANID`、`ACCEPT_SOURCE` 三个参数控制数据范围
