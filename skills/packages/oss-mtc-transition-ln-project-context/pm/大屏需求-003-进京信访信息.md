# 辽宁省军转厅国产化改造项目 - 大屏3：进京信访信息

## 一、整体说明

- **所属模块**：2.3 可视化分析 → 大数据综合展示
- **大屏编号**：3 / 4
- **大屏名称**：进京信访信息
- **数据范围**：进京信访（REG_AUTHORITY=1）
- **结构说明**：本大屏结构与大屏2（辽宁信访信息）完全一致，仅 `REG_AUTHORITY` 参数不同
- **源文档**：辽宁省军转厅国产化改造项目需求说明书（最新-20260805）-2026年8月10日.md
- **父文档**：大屏需求拆解.md

---

## 二、地图联动说明

- **地图能力**：辽宁省行政区划地图，支持两级下钻
    - 第一级：展示各地市数据（cantType=4）
    - 第二级：点击地市下钻到区县（cantType=6），区县不再下钻
    - 其他模块数据随地图下钻联动切换
- **数据合并规则**：沈抚新区（编号2115）数据合并到抚顺市（编号2104）
- **导航切换**：本大屏通过导航按钮与"人员信息""辽宁信访信息""信访数据比对"三个大屏切换

## 四、展示模块3 概要指标明细

- 昨日网上信访量（JTWX）
- 累计网上信访量（ZWX）
- 昨日来访量（JTLF）
- 累计来访量（ZLF）
- 昨日集体访批次（JTJTFPC）
- 昨日集体访人次（JTJTFRC）
- 累计来信量（ZLX）
- 昨日来信量（JTLX）
- 昨日信访量 = JTWX + JTLF + JTLX

## 七、公共参数说明

| 参数          | 含义           | 取值                                       |
| ------------- | -------------- | ------------------------------------------ |
| cantCode      | 行政区域编号   | 省=21，地市/区县传对应编号                 |
| cantType      | 行政区域类型   | 4=地市级，6=区县级                         |
| ORGANID       | 行政区域编号   | 展示哪个区域传对应编号                     |
| REG_AUTHORITY | 登记机构       | **本大屏固定传 1（进京）**                 |
| ACCEPT_SOURCE | 信访形式       | 1=网上信访，2=来访，3=来信，7=特殊人员信访 |
