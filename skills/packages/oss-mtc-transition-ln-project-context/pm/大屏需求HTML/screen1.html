6 部分人员类别就业状况 统计图 ▶
说明
按人员类别分组统计就业状况：已就业、未就业、失业三类人数
指标定义
序号指标名称字段 / 计算方式数据表
1人员类别rylbaa_jycy
2已就业人数SUM(CASE WHEN cbzt='已就业' THEN 1 ELSE 0 END) AS EMPLOYMENTaa_jycy
3未就业人数SUM(CASE WHEN cbzt='未就业' THEN 1 ELSE 0 END) AS UNEMPLOYMENTaa_jycy

SQL 查询
-- 按人员类别分组统计就业状况
SELECT rylb, SUM(CASE WHEN cbzt = '已就业' THEN 1 ELSE 0 END) AS EMPLOYMENT, SUM(CASE WHEN cbzt = '未就业' THEN 1 ELSE 0 END) AS UNEMPLOYMENT, SUM(CASE WHEN cbzt = '失业' THEN 1 ELSE 0 END) AS LOSE_JOB FROM aa_jycy GROUP BY rylb
