大屏2：辽宁信访信息

6个模块 REG_AUTHORITY = 2（本地）

提供辽宁范围信访信息大数据综合展示功能。

1 信访量趋势 折线图 ▶
图表类型
折线图（多系列）
展示维度
最近12个月，分三类信访渠道
数据系列
网上信访（ACCEPT_SOURCE=1）、来访（ACCEPT_SOURCE=2）、来信（ACCEPT_SOURCE=3）
数据字段
NUM_0 ~ NUM_11 分别代表最近12个月的信访量
LETTER_SCREEN_2
SQL 查询语句
-- REG_AUTHORITY=2 代表本地 -- ACCEPT_SOURCE: 1=网上信访, 2=来访, 3=来信, 7=特殊人员信访 SELECT SUM(NUM_0), SUM(NUM_1), SUM(NUM_2), SUM(NUM_3), SUM(NUM_4), SUM(NUM_5), SUM(NUM_6), SUM(NUM_7), SUM(NUM_8), SUM(NUM_9), SUM(NUM_10), SUM(NUM_11) FROM LETTER_SCREEN_2 WHERE REG_AUTHORITY = 2 AND ACCEPT_SOURCE = 1 AND ORGAN_ID = #{ORGANID} GROUP BY ACCEPT_SOURCE ORDER BY ACCEPT_SOURCE （来访 ACCEPT_SOURCE=2，来信 ACCEPT_SOURCE=3，分别执行相同SQL）

3 信访量概要情况 数字 + 列表 ▶
展示形式
关键指标数字卡片 + 详细列表
指标数量
9个核心指标
指标明细（9项）
指标名称字段说明
昨日网上信访量JTWX前一日通过网上渠道提交的信访件数量
累计网上信访量ZWX历史累计网上信访件总数
昨日来访量JTLF前一日来访接待的信访件数量
累计来访量ZLF历史累计来访接待总数
昨日集体访批次JTJTFPC前一日集体上访的批次数量
昨日集体访人次JTJTFRC前一日集体上访的总人次
累计来信量ZLX历史累计收到的来信总数
昨日来信量JTLX前一日收到的来信数量
昨日信访总量yesterday_total= JTWX + JTLF + JTLX（三类渠道昨日合计）
LETTER_SCREEN_6
SQL 查询语句
SELECT JTWX, ZWX, JTLF, ZLF, JTJTFPC, JTJTFRC, ZLX, JTLX, (JTWX + JTLF + JTLX) AS yesterday_total FROM LETTER_SCREEN_6 WHERE REG_AUTHORITY = 2 AND ORGAN_ID = #{ORGANID}
4 各地区地图信访数据 地图（浅蓝→红橙渐变） ▶
