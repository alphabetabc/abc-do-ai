大屏4：信访数据比对

6个模块 本地(2) vs 进京(1) 对比

提供辽宁范围信访数据比对大数据综合展示功能，将本地信访与进京信访数据进行对比展示。

1 信访量趋势对比 折线图 ▶

以折线图展示本地和进京的三类信访渠道（网上信访、来访、来信）的和的最近12个月信息量变化。

LETTER_SCREEN_2
SQL · 本地信访（REG_AUTHORITY=2）
-- 本地信访12个月趋势，按渠道分组后求和 SELECT SUM(NUM_0), SUM(NUM_1), SUM(NUM_2), SUM(NUM_3), SUM(NUM_4), SUM(NUM_5), SUM(NUM_6), SUM(NUM_7), SUM(NUM_8), SUM(NUM_9), SUM(NUM_10), SUM(NUM_11) FROM LETTER_SCREEN_2 WHERE REG_AUTHORITY = 2 AND ORGAN_ID = #{ORGANID} GROUP BY ACCEPT_SOURCE ORDER BY ACCEPT_SOURCE
SQL · 进京信访（REG_AUTHORITY=1）
-- 进京信访12个月趋势，SQL同上，仅 REG_AUTHORITY 改为 1 SELECT SUM(NUM_0), SUM(NUM_1), SUM(NUM_2), SUM(NUM_3), SUM(NUM_4), SUM(NUM_5), SUM(NUM_6), SUM(NUM_7), SUM(NUM_8), SUM(NUM_9), SUM(NUM_10), SUM(NUM_11) FROM LETTER_SCREEN_2 WHERE REG_AUTHORITY = 1 AND ORGAN_ID = #{ORGANID} GROUP BY ACCEPT_SOURCE ORDER BY ACCEPT_SOURCE

3 信访量概要情况对比 数字 + 列表 ▶

顶部展示昨日信访量、昨日集体访批次、昨日集体访人次；下方展示各渠道信访量。 每个指标同时展示：合计 = 本地 + 进京。

指标取值字段对比说明
昨日网上信访量JTWX合计 = 本地(JTWX, REG=2) + 进京(JTWX, REG=1)
累计网上信访量ZWX合计 = 本地 + 进京
昨日来访量JTLF合计 = 本地 + 进京
累计来访量ZLF合计 = 本地 + 进京
昨日集体访批次JTJTFPC合计 = 本地 + 进京
昨日集体访人次JTJTFRC合计 = 本地 + 进京
累计来信量ZLX合计 = 本地 + 进京
昨日来信量JTLX合计 = 本地 + 进京
昨日信访量JTWX + JTLF + JTLX三渠道之和；合计 = 本地SUM + 进京SUM
LETTER_SCREEN_6
SQL · 本地信访（REG_AUTHORITY=2）
SELECT JTWX, ZWX, JTLF, ZLF, JTJTFPC, JTJTFRC, ZLX, JTLX, (JTWX + JTLF + JTLX) AS yesterday_total FROM LETTER_SCREEN_6 WHERE REG_AUTHORITY = 2 AND ORGAN_ID = #{ORGANID}
SQL · 进京信访（REG_AUTHORITY=1）
SELECT JTWX, ZWX, JTLF, ZLF, JTJTFPC, JTJTFRC, ZLX, JTLX, (JTWX + JTLF + JTLX) AS yesterday_total FROM LETTER_SCREEN_6 WHERE REG_AUTHORITY = 1 AND ORGAN_ID = #{ORGANID}
