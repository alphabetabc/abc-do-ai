1
进京信访量趋势
折线图 ▶
功能说明
展示最近12个月进京信访量趋势，按渠道（网上信访、来访、来信）分组展示三条折线
图表类型
多系列折线图（3条线：网上信访、来访、来信）
核心指标
最近12个月每个月各渠道进京信访件数量
关联API
/service/vetertans/letter/getLettersTrendData（POST）
涉及数据表
LETTER_SCREEN_2

请求参数

参数名类型必填说明

typeString是数据类型标记，非空值触发 REG_AUTHORITY=1（进京）

SQL 查询

getLettersTrendData · ILetterScreenMapper.xml 
SELECT
    SUM(NUM_0)  NUM_0,
    SUM(NUM_1)  NUM_1,
    SUM(NUM_2)  NUM_2,
    SUM(NUM_3)  NUM_3,
    SUM(NUM_4)  NUM_4,
    SUM(NUM_5)  NUM_5,
    SUM(NUM_6)  NUM_6,
    SUM(NUM_7)  NUM_7,
    SUM(NUM_8)  NUM_8,
    SUM(NUM_9)  NUM_9,
    SUM(NUM_10) NUM_10,
    SUM(NUM_11) NUM_11
FROM
    LETTER_SCREEN_2
WHERE
    ORGAN_ID = #{code,jdbcType=VARCHAR}
    AND REG_AUTHORITY = 1
GROUP BY ACCEPT_SOURCE
ORDER BY ACCEPT_SOURCE

响应字段说明

字段说明备注
NUM_0 ~ NUM_11第0月~第11月进京信访数量共12个月份，NUM_11为最近1个月
ACCEPT_SOURCE信访渠道分组1=网上信访, 2=来访, 3=来信（共3条记录）

📊 渠道分组说明
ACCEPT_SOURCE = 1 → 网上信访 ACCEPT_SOURCE = 2 → 来访 ACCEPT_SOURCE = 3 → 来信 共返回 3 条记录，每条记录含上述 11 个身份字段

公共参数汇总

参数名含义大屏3取值备注
cantCode / ORGAN_ID行政区域编号省级初始=21，钻取传对应编码省=21，地市=4位，区县=6位
cantType行政区域类型省级视图=4，下钻区县=64=地市级，6=区县级
REG_AUTHORITY登记机构= 1（进京）1=进京，2=本地，0=未添加
ACCEPT_SOURCE信访形式按接口自动分组1=网上信访，2=来访，3=来信
