## 1. 背景与选型决策

- 需求：041 比对大屏模块 2「信访主要诉求占比对比」，圆形雷达 + 多系列对比
- **选型变更**：ECharts radar 系列不支持 `smooth`，category 极坐标下追加起点值闭合是近似（幽灵点偏移一格扇区）；value 角度轴方案可精确闭合但 label/splitLine 成本高。最终改用 **@ant-design/plots v2 Radar**（G2 极坐标），`shapeField: 'smooth'` 原生平滑且闭合正确
- D1 选型随之为「ECharts + echarts-for-react **+ @ant-design/plots 2.6.8** 并存」（AGENTS.md §5.5 已含 plots，用户已安装依赖）

## 2. 实施内容

### 2.1 组件（radar-chart）

- 多系列：长表数据 + `colorField: 'series'`，颜色按传入顺序 `scale.color.range`
- y 轴双模式：全维度未传 `max` → 原始值直喂，域 `[0, ceil(overallMax × 1.05)]` 抑制 nice headroom；任一传 `max` → 归一化 0–100
- 视觉规格：圆圈轴 2px 实线 `rgba(241,241,241,1)`、辐条虚线 `[2,2]` 白、分割区灰透明交替 0.15、label Source Han Sans CN 16px/500 `rgba(166,190,206,1)`、无线条数据点（线 + 面积填充，areaOpacity 默认 0.2）
- 图例：弃 G2 内置 legend（受负 padding 挤压），HTML 覆盖层 `top:0 right:0` 贴容器顶边；点击联动切换系列显隐（hiddenNames state，至少保留一个可见系列）
- 尺寸：组件 100%×100% 撑满父级 + `autoFit`；padding 默认 `-20`（负值压缩留白放大雷达）；中途试过 `[-40,-64,-64,-64]` 与 scale.x padding 0→0.5 回调等迭代，最终回到 `-20`
