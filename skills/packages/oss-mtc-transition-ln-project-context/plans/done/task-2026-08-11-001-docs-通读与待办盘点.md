### Step 5 · 整理「在 docs 中开展大屏任务的步骤」（**核心产出**）

按 SDD 流程 + `ai-prompts-guide.md` §2 / §3，列出 docs 视角下的步骤。每步标「前置依赖 / 阻塞决策 / 输出文件 / L 等级」。

预期步骤骨架（实际以通读结果为准）：

1. 在 `docs/specs/index.md` 分配编号与目录名（如 `036-…`）
2. 复制 `docs/specs/_template/` 五件套到新目录
3. 把 PM 输入迁移到 `docs/specs/{NNN}/pm-inputs/`（assets + `pm-requirements-input.md`）
4. 在 `docs/design/data-models.md` §6 / §7 确认/扩展统计表模型
5. 在 `docs/design/api-contracts.md` §7.4x + OpenAPI 登记端点
6. 在 `docs/design/architecture.md` 数据库章节登记（如有新表/视图）
7. 在 `docs/design/system-overview.md` §2.2.2 对齐菜单/路由
8. 在 `docs/specs/{NNN}/spec.md` §0 写技术决策（图表选型等）
9. 按 `docs/ai-prompts-guide.md` §2.2 分轮生成五件套（spec → extensions → acceptance → plan/tasks）
10. 按 `docs/workflows/tdd-process.md` 写 acceptance-tests 与单测
11. 联调后更新 `AGENTS.md` §2.1 表格、`docs/specs/index.md` 状态列
