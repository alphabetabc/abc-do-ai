### 7.43 进京信访大屏（040，`/api/visual/big-screen/beijing-petition/*`）

> 功能 Spec：`docs/specs/040-bigdata-beijing-petition-display/spec.md`。实现路由：`backend/app/api/visual/big_screen/beijing_petition/router.py`（**无** `/v1` 前缀）。数据源：`dw_basic_lc.letter_screen_1`~`6`（见 `docs/design/data-models.md` §7）。

#### 通用约定

| 项     | 约定                                                                          |
| ------ | ----------------------------------------------------------------------------- |
| 认证   | Header：`Authorization: Bearer <access_token>`；缺失或无效 → **401**          |
| 权限   | 菜单 key `visual-big-screen-beijing-petition`；无权限 → **403**（菜单项粒度） |
| 响应   | **200**，`ApiResponse`（`{ code, message, data }`）                           |
| 幂等   | 是（GET）                                                                     |
| 数据域 | `REG_AUTHORITY=1`（上京），所有端点通用（与 039 的 `=2` 区分）                |

#### 通用 Query 参数

| 参数       | 类型   | 必填 | 说明                                                                           |
| ---------- | ------ | ---- | ------------------------------------------------------------------------------ |
| `organId`  | string | 否   | 组织/行政区域编号；省维度 `210000`（默认），市维度如 `210100`，区县如 `210102` |
| `cantType` | string | 否   | 行政区域类型：`4` 市（地图第一层），`6` 县区（地图下钻后）                     |

> `organId` 用于模块 1/2/3/5/6 的单区域查询；`cantType` 用于模块 4 的区域列表查询。两者互斥使用。

#### 统一 `data` 字段结构

`data: { items: Item[] }`，`Item` 形状（同 §7.41/§7.42）：

```typescript
{
  key: string;
  name: string;
  value: number;
  unit: string;
  label?: string;
  type?: string;
}
```

> 模块3 例外：`data` 含 8 个扁平字段（`jtwx, zwx, jtlf, zlf, jtJtfpc, jtJtfrc, zlx, jtlx`），非 `items[]` 结构；前端派生 `yesterdayTotal = jtwx + jtlf + jtlx`。

#### 端点清单（6 个）

| Path                                               | 模块  | 图表类型          | `data` 形状                                            | operationId                           |
| -------------------------------------------------- | ----- | ----------------- | ------------------------------------------------------ | ------------------------------------- |
| `/api/visual/big-screen/beijing-petition/trend`    | 模块1 | 折线图            | `items[36]`（3 渠道 × 12 月；含 `label`）              | `getBigScreenBeijingPetitionTrend`    |
| `/api/visual/big-screen/beijing-petition/appeal`   | 模块2 | 环形饼图          | `items[N]`（N = 实际事项数）                           | `getBigScreenBeijingPetitionAppeal`   |
| `/api/visual/big-screen/beijing-petition/overview` | 模块3 | 数字卡片+渠道卡片 | 8 扁平字段（非 items[]）                               | `getBigScreenBeijingPetitionOverview` |
| `/api/visual/big-screen/beijing-petition/map`      | 模块4 | 地图热力图        | `items[14]`（按 cantCode 唯一；沈抚 2115 合并到 2104） | `getBigScreenBeijingPetitionMap`      |
| `/api/visual/big-screen/beijing-petition/rank`     | 模块5 | 柱状图            | `items[14]`（`label` = `MAX_TIME`）                    | `getBigScreenBeijingPetitionRank`     |
| `/api/visual/big-screen/beijing-petition/identity` | 模块6 | 分组柱状图        | `items[33]`（11 类身份 × 3 渠道；含 `type`）           | `getBigScreenBeijingPetitionIdentity` |

> 040 与 039 共享同一组 `letter_screen_*` 6 张表，唯一口径差异为 `REG_AUTHORITY=1`（上京）vs 039 的 `=2`（本地）；模块3 扩展为 9 项卡片（3 数字 + 6 渠道），039 仅 3 项数字卡片。
