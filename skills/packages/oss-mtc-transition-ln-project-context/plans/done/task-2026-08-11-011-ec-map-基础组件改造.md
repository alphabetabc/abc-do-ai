# Task 011 · ec-map 地图组件基础改造

> 状态：✅ 完成
> 分支：基础组件封装
> 日期：2026-08-11

---

## 1. 背景

`frontend/src/components/large-screen/ec-map/` 下已有从外部项目迁移来的地图组件代码（3 个文件），依赖大量本仓库不存在的模块，无法编译。

本 task 范围：**仅做依赖替换 + 类型补全**，使组件在本仓库可编译、可运行。不改变功能逻辑，不新增功能。

## 3. 依赖替换映射

| 原依赖                                                | 替换为               | 备注                                                                                  |
| ----------------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------- |
| `@fedx-web-common/react-hooks`                        | `ahooks`             | `useSetState`/`useLatest`/`useMemoizedFn`/`useRequest` API 一致                       |
| `@fedx-web-common/utils`（`isEmpty`/`isEqual`）       | 原生实现             | `isEmpty`→`arr.length===0`/`obj==null`；`isEqual`→`JSON.stringify` 对比或简单引用对比 |
| `~/web/components/large-screen/lib`（`ReactECharts`） | `echarts-for-react`  | `import ReactECharts from 'echarts-for-react'`                                        |
| `~/web/common/map-config`（`getMapConfig`）           | **移除**，留 TODO    | 地图区域配置数据来源未定，记入 memo                                                   |
| `~/web/services/request`（`loadJson`）                | `axios`              | 直接 `axios.get(url).then(res => res.data)`                                           |
| `~/web/common/constants`（`STATIC_PATH`）             | 内置默认值 `''`      | 留 TODO 待配置                                                                        |
| `~/web/utils`（`isDefined`）                          | 原生 `!= null`       | -                                                                                     |
| `../../data-status`（`FedxDataStatus`）               | antd `Spin`/`Result` | loading→`Spin`，error→`Result`                                                        |
| `classnames` / `cx`                                   | 模板字符串           | 大屏组件无需复杂 class 合并                                                           |

---

## 4. 改造原则

1. **不改变功能逻辑**：option 构建、overlay 坐标转换、事件绑定等核心逻辑保持原样
2. **不新增功能**：下钻、tooltip 增强、数据联动等留到后续 task
3. **类型补全**：原代码大量 `any`，改造时对 Props 和 hook config 补 TypeScript 类型
4. **待定项标 TODO**：`getMapConfig`、`STATIC_PATH` 等无法确定的数据源留 `// TODO(task-011):` 标记
5. **Fast Refresh 兼容**：`index.tsx` 只导出组件，hook / context 分文件
