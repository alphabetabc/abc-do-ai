## 2. 交互设计

### 2.1 交互总表

| 视图                               | 操作           | 行为                                                             | 实现机制                                                                                        |
| ---------------------------------- | -------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 省级（cantType='4'，辽宁 14 地市） | **双击**地市   | 下钻一层：`setOrganId(adcode,'6')` → 全模块刷新 + 地图切市级视图 | `onDblClick`（`item.level === 'city'`）+ `prevCantTypeRef` 视图 effect（task-060 机制保留不动） |
| 省级                               | 单击地市       | 无操作                                                           | 省级不传 `geoSelectedMode`（无原生选中高亮）+ 业务侧不再绑 onClick                              |
| 市级（cantType='6'，地市区县）     | **单击**区县   | 选中高亮 + `setOrganId(区县adcode,'6')` 全模块联动               | geo `selectedMode: 'single'` 原生 toggle + `geoselectchanged` 事件                              |
| 市级                               | 再单击已选区县 | 原生 toggle 取消选中 → organId 回市级口径 ✅ review 已确认       | `geoselectchanged` name=[] 分支                                                                 |
| 市级                               | **点击空白处** | 清除选中（`geoUnSelect`）+ organId 回市级口径 ✅ review 已确认   | zrender click `!params.target` → `onBlankClick`                                                 |
| 市级                               | 双击区县       | 不下钻（忽略）                                                   | `onDblClick` 中 `level !== 'city'` 早退（「到下一层就不下钻」天然满足：市级数据全为 district）  |
| 非省级                             | 顶部返回按钮   | `setOrganId('210000','4')` 直达省级（**不变**）                  | 页面 `petition-comparison/index.tsx` 现有逻辑保留                                               |

### 2.2 已知边界（推演结论）

- **市级双击未选区县**：dblclick 前会到 click×2 → 原生 toggle 选中→取消，organId 往返（市级→区县→市级）两轮刷新，瞬态无害（refreshDeps 值不变时不重拉）；不做 dblclick 抑制（避免过度设计）
- **省级双击下钻**：先到的两次 click 无副作用（省级无 selectedMode、业务侧无 onClick）
- **geoSelectedMode 时效**：仅随视图切换变化，且省↔市 adcode 必变 → `useGeoOption`（useMemo deps `[config.adcode]`）重建时 selectedMode 同步生效，无 stale 风险
- **选中残留**：视图切换时 geo option 经 `replaceMerge:['geo','series']` 重建天然清选中；业务侧在视图 effect 中防御性 `dispatchAction({type:'geoUnSelect', geoIndex:2})`（ecRef 取实例，可选链跳过未就绪）
- **geoUnSelect 清全部**：dispatch 不带 name = 取消全部选中（ECharts 约定）；若实测不生效，fallback 为 onGeoSelectChanged 维护 selectedNames 逐个取消

### 2.3 ec-map 共享组件 additive 设计（038/039/040 零影响）

新增 props 全部默认 `undefined`，不传即完全现行为：

1. **option.tsx**：`GeoOptionConfig`/`ECMapOptionConfig` 加 `geoSelectedMode?: 'single' | 'multiple'`；顶层可交互 geo（geoIndex 2）加 `selectedMode: config.geoSelectedMode`（undefined → ECharts 默认 false）+ `select: { itemStyle: { color: 'rgba(255,255,255,0.5)' }, label: { color: '#fff', fontSize: 14 } }`（与现有 emphasis 一致，写死）
2. **map.tsx**：
    - `MapProps` 加 `geoSelectedMode` + `onGeoSelectChanged?: (info, instance) => void` + `onBlankClick?: (instance) => void`
    - `useECMapOption` 透传 `geoSelectedMode`
    - 事件绑定 useLayoutEffect（deps `[ecInstance]`）内追加：`ecInstance.on('geoselectchanged', ...)`（分支置于 emit 的 `componentType === 'geo'` 判断**之前**，payload `name` 为数组，解析为 `{ selectedNames: string[], items: [{data,type:'geo',rawParams}], rawParams }`）；`ecInstance.getZr().on('click', e => { if (!e.target) props.onBlankClick?.(ecInstance) })`
3. **index.tsx**：`EChartsMapProps` 接口同步三 props（守卫壳 `<Map {...props} />` 全量转发自动生效）

> 组件层转发事件而非业务侧经 ecRef 自行绑定：规避 ecRef（useImperativeHandle deps `[ecInstance]`）实例就绪时序问题。
