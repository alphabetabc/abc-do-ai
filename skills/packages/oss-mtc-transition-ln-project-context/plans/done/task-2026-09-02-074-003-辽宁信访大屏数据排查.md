### 4.6 快照过滤统一改「按天」：10 个 SQL 位置清单（用户已拍板 2026-09-03）

> 排查清单（历史勾选见上方各节）：
>
> - [x] 模块4/5 沈抚合并 → 前缀匹配修复（§4.2）
> - [x] 模块4/5 柱图单位「万」错标 → 改「件」（§4.3）

**决议**：`STATS_DATE = (SELECT MAX(STATS_DATE) ...)` 精确到秒，而本地库同一天内各层级时间戳不同步（省 23:00:00 / 市 23:00:01 / 区县 23:00:04）→ 省级/市级行被静默排除。统一改为**按天**取最新：

```sql
CAST(STATS_DATE AS DATE) = (
    SELECT MAX(CAST(STATS_DATE AS DATE))
    FROM dw_basic_lc.<同表>
    WHERE <同过滤条件>
)
```

**来源追溯**：`MAX(STATS_DATE)` 为 commit `2f3fb53`（孙寰哲 2026-09-01「辽宁大屏下钻数据联动显示调整」）实现时自行采用 O-14 候选①；PM 输入（pm-requirements-input.md §4.3 L72-74）与 spec 示例 SQL 均无此条件。O-14 现由用户拍板为「按天」。
