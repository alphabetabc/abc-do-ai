### 0.5 路由方案演进（最终方案：单路由 + query 切换）

本 task 路由方案经多轮演进，最终定为**单路由 + query 参数切换**：

| 模块             | PM 原文路由                      | 实现路由                                     | menu 参数（驼峰）    | 物理目录                                       |
| ---------------- | -------------------------------- | -------------------------------------------- | -------------------- | ---------------------------------------------- |
| 人员信息大屏     | `/bigdata/personnel`             | `/visual/big-screen?menu=personnel`          | `personnel`          | `pages/visual/big-screen/personnel/`           |
| 辽宁信访大屏     | `/dashboard/petition`            | `/visual/big-screen?menu=petition`           | `petition`           | `pages/visual/big-screen/petition/`            |
| 进京信访大屏     | `/dashboard/beijing-petition`    | `/visual/big-screen?menu=beijingPetition`    | `beijingPetition`    | `pages/visual/big-screen/beijing-petition/`    |
| 信访数据比对大屏 | `/dashboard/petition-comparison` | `/visual/big-screen?menu=petitionComparison` | `petitionComparison` | `pages/visual/big-screen/petition-comparison/` |

**方案要点**：

- 路由仍走 AppShell children（`appRoutes`），保留登录校验 + tab 体系
- 单路由 `visual/big-screen`，子页通过 `?menu=xxx`（驼峰 key）切换
- Visual 组件内用 `useSearchParams` 读 `menu`，`lazy` 加载对应子页，`Suspense` 包裹
- `menu` 缺省时默认 `personnel`；未知 menu 显示「未知大屏：xxx」
- 切换 menu 参数时 pathname 不变 → tab 不重复创建

**已废弃的方案**（记录演进过程）：

1. ❌ 4 子路由 `/visual/bigdata/personnel` 等 + 父路由 `<Visual><Outlet/></Visual>`：被 AppShell 套住，大屏内容困在 tab 卡片里
2. ❌ 顶级路由 `/visual/big-screen`（脱离 AppShell）：tab 不创建，但脱离菜单体系
3. ❌ ROUTE_WHITELIST 白名单 4 条 + AppShell 跳过 tab 创建：绕过鉴权，违反 AGENTS §4/§8
4. ✅ 单路由 + query 切换（最终方案）
