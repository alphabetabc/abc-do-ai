## 2. 决策理由

- **粒度最细**：每个 spec 只关注 1 屏，spec.md 大小可控，验收范围清晰
- **独立验收**：每屏可独立走 M0→M5 全流程，不互相阻塞
- **pm-input 独立**：每屏有独立 PM 输入（4 份分屏 md + 对应设计稿），天然对应 4 份 pm-input
- **代价可接受**：4 份五件套维护成本高，但公共组件（图表壳/翻牌/地图）可在 spec §4 或独立 `docs/skills/frontend/react/` 章节统一约定，避免重复
