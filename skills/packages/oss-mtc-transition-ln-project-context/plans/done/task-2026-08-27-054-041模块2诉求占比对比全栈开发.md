### 7.44 信访数据比对大屏（041，`/api/visual/big-screen/petition-comparison/*`）

> 功能 Spec：docs/specs/041-bigdata-petition-comparison-display/spec.md。
> 实现路由：backend/app/api/visual/big_screen/petition_comparison/router.py（**无** `/v1` 前缀）。
> 数据源：dw_basic_lc.letter_screen_1~6（见 docs/design/data-models.md §7）。

#### 通用约定

| 项     | 约定                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| 认证   | Header：`Authorization: Bearer <access_token>`；缺失或无效 → **401**                      |
| 权限   | 菜单 key `visual-big-screen-petition-comparison`；无权限 → **403**（菜单项粒度鉴权）      |
| 响应   | **200**，`ApiResponse`（`{ code, message, data }`）                                       |
| 幂等   | 是（GET）                                                                                 |
| 数据域 | `REG_AUTHORITY=2`（本地）+ `=1`（进京）双查询；模块 4 单端点 `IN (1, 2)` 聚合（后续登记） |

#### 通用 Query 参数

| 参数      | 类型   | 必填 | 说明                                                                                                                                                          |
| --------- | ------ | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `organId` | string | 否   | 组织/行政区域编号，6 位标准码（省 `210000` 默认，市如 `210100`）；Service 层右补 `'0'` 至 9 位对齐实库 `ORGAN_ID`（`210000000` 格式；沈抚实际码 `211500000`） |

#### 统一 `data` 字段结构

`data: { items: Item[] }`，`Item` 形状（同 §7.41–§7.43）：

```typescript
{
  key: string;       // 唯一键
  name: string;      // 展示名
  value: number;     // 数值
  unit: string;      // 单位
  label?: string;    // 可选副标签
  type?: string;     // 可选分组键
}
```

#### GET `/appeal`（模块2：信访主要诉求占比对比）详述

Query：`organId`（可选，默认 `210000`）。

**口径**：

- 表 `dw_basic_lc.letter_screen_1`；双查询：`REG_AUTHORITY=2` → type=`local`、`=1` → type=`beijing`
- 维度 = `ITEM_NAME`（实测为 9 个分类名：退役安置类/优待抚恤类/就业创业类/褒扬纪念类/军休服务类/帮扶援助类/党员管理类/咨询建议类/其他）；`REG_MAIN_APPEAL_ONE` 为对应字典码 '1'~'9' → 放入 `label`
- `NUM` varchar 可能 NULL → Service 层按 0 处理并 CAST int；同组内按 `(ITEM_NAME, REG_MAIN_APPEAL_ONE)` 聚合 SUM
- 沈抚合并：查询市级行含抚顺（`210400000`）时同时取 `ORGAN_ID='211500000'` 行数值相加并入本组
- 空 / 无匹配 → **200** + `items: []`

**item 形状**：

```typescript
{
  key: string;     // appeal_<type>_<label>，如 "appeal_local_3"
  name: string;    // ITEM_NAME 分类名（雷达维度）
  value: number;   // NUM 聚合值（int）
  unit: "件";
  label?: string;  // REG_MAIN_APPEAL_ONE 码
  type: "local" | "beijing";  // 对比分组
}
```

**OpenAPI 片段**：

```yaml
/appeal:
  get:
    operationId: getBigScreenPetitionComparisonAppeal
    parameters: [{ name: organId, in: query, schema: { type: string } }]
    responses:
      '200': { description: ApiResponse<{ items: Item[] }> }
      '401': { $ref: '#/components/responses/Unauthorized' }
      '403': { $ref: '#/components/responses/Forbidden' }
```
