### 2.4 数据口径

| 端点       | 源表                          | 查询次数 | 派生                |
| ---------- | ------------------------------ | -------- | ------------------- |
| `/map`     | `dw_basic_lc.letter_screen_4` | 1 次     | -                   |
| `/summary` | `dw_basic_lc.letter_screen_6` | 2 次     | `summary[]` 数组    |
| `/channels`| `dw_basic_lc.letter_screen_6` | 2 次     | `channels[]` 数组   |

**SQL（地图 /map：1 次单查询）**：

```sql
SELECT CANT_NAME, CANT_CODE, SUM(NUM) AS NUM
FROM dw_basic_lc.letter_screen_4
WHERE REG_AUTHORITY IN (1, 2)
  AND ORGAN_ID = :organId
GROUP BY CANT_NAME, CANT_CODE
```

**SQL（/summary + /channels：双查询 = 2 次）**：

```sql
-- 本地（summary 派生用 JTWX/JTJTFPC/JTJTFRC；channels 派生用 JTWX/ZWX/JTLF/ZLF/ZLX/JTLX）
SELECT JTWX, ZWX, JTLF, ZLF, JTJTFPC, JTJTFRC, ZLX, JTLX
FROM dw_basic_lc.letter_screen_6
WHERE REG_AUTHORITY = 2
  AND ORGAN_ID = :organId

-- 进京（同上结构，REG_AUTHORITY=1）
```

**Service 层派生公式（/summary）**：

```python
summary = []
for k, label, unit in [
    ("yesterdayPetition",       "昨日信访量",     "件"),
    ("yesterdayBatchFrequency", "昨日集体访频次", "次"),
    ("yesterdayBatchPeople",    "昨日集体访人次", "人次"),
]:
    summary.append({
        "key": k,
        "label": label,
        "value": local[k] + beijing[k],  # Service 派生合计
        "unit": unit
    })
```

**Service 层派生公式（/channels）**：

```python
channels = []
for period, prefix in [("yesterday", "j"), ("cumulative", "z")]:
    # 本地 + 进京合并
    data = {
        "web":    local[f"{prefix}wx"]    + beijing[f"{prefix}wx"],
        "visit":  local[f"{prefix}lf"]    + beijing[f"{prefix}lf"],
        "letter": local[f"{prefix}{'lx' if prefix == 'j' else 'lx'}"] + beijing[...],
    }
    for label, value in [("来访", data["visit"]), ("来信", data["letter"]), ("网络", data["web"])]:
        channels.append({
            "period": period,
            "label": label,
            "value": value,
            "unit": "件"
        })
```
