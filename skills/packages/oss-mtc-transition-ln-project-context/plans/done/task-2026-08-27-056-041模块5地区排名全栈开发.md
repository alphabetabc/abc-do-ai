## 2. 数据口径速览（详见 041 spec §3.3 模块5 + dme §2.5）

- 表：`dw_basic_lc.letter_screen_5`
- 字段：`CANT_NAME` / `CANT_CODE` / `NUM` / `ORGAN_ID` / `MAX_TIME`(varchar(50)) / `REG_AUTHORITY` / `STATS_DATE`
- 查询次数：**2 次**（本地 `REG_AUTHORITY=2` + 进京 `REG_AUTHORITY=1`）
- Service 层处理：双查询各 `ORDER BY NUM DESC`；沈抚合并（`211500000` 行并入 `210400000` 抚顺行 × 2 组）
- 响应形状（spec §3.3 / dme §2.5）：
    ```typescript
    {
      local: { regions: [
        { cantName: '沈阳市', cantCode: '210100000', num: 1234, maxTime: '2026-05-17' },
        ...
      ] },
      beijing: { regions: [...] }
    }
    ```
- 单位：万（前端 `labelFormatter` 换算：`num × 10000` → 显示整数）
- 复用件（task-054 已落地）：
    - `query_local_and_beijing(organ_id, sql_template, params)` 双查询抽象
    - `organId` Service 层右补 `'0'` 至 9 位（如 `210000` → `210000000`）
    - 沈抚合并（`211500000` 行并入 `210400000` 抚顺行 × 2 组）
