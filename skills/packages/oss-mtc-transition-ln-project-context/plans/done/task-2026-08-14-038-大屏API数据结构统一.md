## 1. 决策背景

### 1.1 问题

当前 4 个大屏 spec 的 API `data` 字段有 6 种形态，前端需为每种形态写特判渲染逻辑：

| 形态        | 示例端点            | 当前结构                                                   |
| ----------- | ------------------- | ---------------------------------------------------------- |
| 扁平对象    | 038 `/veteran`      | `{ veteran, officer, officerRatio, ... }`                  |
| 对象+数组   | 038 `/total/detail` | `{ items: [{ label, value }] }`                            |
| 嵌套数组    | 038 `/map`          | `{ regions: [{ statsUnitName, veteran }] }`                |
| series 数组 | 039 `/trend`        | `{ series: [{ name, data: number[] }] }`                   |
| 分组柱状图  | 038 `/employment`   | `{ categories: string[], series: [{ name, data: [] }] }`   |
| 双组对比    | 041 `/trend`        | `{ local: { series: [...] }, beijing: { series: [...] } }` |

### 1.2 目标结构

统一为：

```typescript
data: {
    items: Array<{
        key: string; // 唯一标识（如 "veteran"、"2101"、"employment_1"）
        name: string; // 显示名称（如 "退役军人总数"、"沈阳市"）
        value: number; // 数值
        unit: string; // 单位（"人" / "万" / "%"）
        label?: string; // 分组标签（分组柱状图的图例，如 "已就业"）
        type?: string; // 可选类型区分（如 "local" / "beijing"，041 对比用）
    }>;
}
```

### 1.3 各图表类型的适配

| 图表类型                  | 用到的字段                                              | 示例                                                                                    |
| ------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 饼图 / 数字卡片 / 条形图  | `key` + `name` + `value` + `unit`                       | `[{ key: "officer", name: "退役军官", value: 3000, unit: "人" }]`                       |
| 地图 / 柱状图（区域列表） | `key` + `name` + `value` + `unit`                       | `[{ key: "2101", name: "沈阳市", value: 5000, unit: "人" }]`                            |
| 折线图（多 series）       | `name`（系列名）+ `label`（X 轴月份）+ `value` + `unit` | `[{ key: "trend_0_ws", name: "网上信访", value: 120, unit: "件", label: "2026-01" }]`   |
| 分组柱状图（二维矩阵）    | `name`（X 轴分组）+ `label`（图例）+ `value` + `unit`   | `[{ key: "emp_1_1", name: "自主就业义务兵", value: 100, unit: "万", label: "已就业" }]` |
| 041 对比（双组）          | 同上 + `type` 区分 local/beijing                        | `[{ ..., type: "local" }, { ..., type: "beijing" }]`                                    |

## 2. 改动范围

### 2.1 038 人员信息大屏（7 端点）

| 端点            | 当前形态              | 改动                                                                                                                        |
| --------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `/veteran`      | 扁平对象 → items 数组 | `{ veteran, officer, ... }` → `items: [{ key: "veteran", name: "退役军人总数", value, unit: "人" }, ...]`                   |
| `/total`        | 扁平对象 → items 数组 | 同上                                                                                                                        |

| `/preferential` | 扁平对象 → items 数组 | 同 /veteran 模式                                                                                                            |
