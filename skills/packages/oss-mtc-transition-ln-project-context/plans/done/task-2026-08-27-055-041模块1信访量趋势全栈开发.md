## 2. 数据口径速览（详见 041 spec §3.3 模块1 + dme §2.1）

- 表：`dw_basic_lc.letter_screen_2`
- 字段：`NUM_0`~`NUM_11`（varchar(64)，`STATS_DATE` datetime 取最新快照行）
- 查询次数：**6 次**（本地 `REG_AUTHORITY=2` × `ACCEPT_SOURCE ∈ {1,2,3}` = 3 次 + 进京 `REG_AUTHORITY=1` × `ACCEPT_SOURCE ∈ {1,2,3}` = 3 次）
- Service 层处理：`CAST(NUM_i AS DECIMAL)`，NULL → 0；沈抚合并（`ORGAN_ID='211500000'` 行数值并入 `210400000` 抚顺行 × 2 组）；X 轴左对齐 `STATS_DATE` 最新月
- 响应形状（spec §3.3）：
  ```typescript
  {
    local: { series: [
      { name: '本地-网上信访', data: [12, 13, ..., 23] },  // 12 个数
      { name: '本地-来访',     data: [...] },
      { name: '本地-来信',     data: [...] }
    ] },
    beijing: { series: [
      { name: '进京-网上信访', data: [...] },
      { name: '进京-来访',     data: [...] },
      { name: '进京-来信',     data: [...] }
    ] }
  }
  ```
- 单位：万（前端 `labelFormatter` 换算）
- 复用件（task-054 已落地）：
  - `query_local_and_beijing(organ_id, sql_template, params)` 双查询抽象
  - `organId` Service 层右补 `'0'` 至 9 位（如 `210000` → `210000000`）
  - 沈抚合并（`211500000` 行并入 `210400000` 抚顺行，本地 + 进京各合并 1 次）
