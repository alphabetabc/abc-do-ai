## 0.2 现象

四个大屏（038/039/040/041）的各业务模块在以下场景下"无数据"展示**不一致 / 不友好**：

- **加载态**：组件挂载或下钻时是否显示 Spin
- **空数据态**：接口返回 `items=[]` 或 `null` 时的展示
- **错误态**：接口失败（非 401）时的展示
- **兜底态**：`enableMock=false` 关闭兜底时，`request.ts` 拦截器返回 `{ code:200, data:{} }`，前端是否合理处理
