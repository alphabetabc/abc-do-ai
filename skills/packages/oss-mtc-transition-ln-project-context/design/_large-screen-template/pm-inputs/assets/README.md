# `_template/assets` — 模板用静态资源

本目录存放 **仅与 PM 输入模板、示例文档相关** 的图片或附件（例如培训示意图、空白稿导出）。

- **特性正式需求**的切图与说明：请放在 **`docs/specs/<编号-短名>/assets/`**，与对应 `spec.md` 同层级，便于评审与版本与特性对齐。
- 在 `pm-requirements-input.md` 或 `pm-requirements-input-example.md` 中引用本目录文件时，使用与这两份 Markdown 的相对路径，例如：`![说明](./assets/example-wireframe.png)`。

若目录为空属正常；有附件时再提交具体文件。
