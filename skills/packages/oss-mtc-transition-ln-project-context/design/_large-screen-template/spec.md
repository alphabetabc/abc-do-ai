## 8. 共享能力

> 开发过程中识别出可被多个大屏复用的公共组件/能力时，在此登记。  
> 识别方式：**AI 识别 + 人确认**——AI 生成 spec 时主动识别并标记"建议共享"，人 review 后标记"确认共享"或"不共享"。  
> 确认共享的，在 `docs/specs/NNN-components-common/` 下新增组件子目录（三件套）。  
> 生成共享 spec 前必须检查 `docs/specs/` 下是否已有共享组件 spec 目录。  
> **强约束**：标记"确认共享"的，对应 task 必须作为前置依赖先完成，不能跳过。
