# user-story-map.md

## 角色

- 省级应急值守 / 指挥人员：统筹全省态势，跨地市调度。
- 市级应急值守人员：盯本地受损与资源，执行调度。
- 开发 / 维护者：基于文档契约对接后端，扩展大屏模块。

## 主旅程

1. 接入应急任务：header 选择任务，确认响应级别（省 / 市）。
2. 看态势：center GIS 双视图——应急传输（故障点、线路、资源打点）与预警感知（天气、水情、高风险乡镇、台风路径）。
3. 查资源：left 应急资源面板，钻取队伍 / 人员 / 油机 / 预置物资详情。
4. 派调度：right 调度任务汇总与工单状态，跨地市调度飞线。
5. 盯受损恢复：right 网络规模指标与乡镇受损下钻，left 实时影响与保障进度。
