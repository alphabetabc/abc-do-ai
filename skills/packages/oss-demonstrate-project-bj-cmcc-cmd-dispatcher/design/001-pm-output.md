## 一、交付范围（一句话）

**两日内交付可在录屏中完整演示 3 大核心场景的北京移动网络信息门户大屏 Demo**，基于静态地图图片 + 写死数据，无需服务端。

---

## 二、核心场景（录屏脚本基线）

### 场景 1：多层级下钻 + 多图层 + 故障报告
- **路径**：分公司 → 石景山区 → 广宁街道 → 某社区 → 物理站 → 逻辑站
- **图层切换**：退服分布 / 物资 / 车辆 / 人员位置（至少 2 个图层可切换）
- **故障报告**：在分公司、区、街道三级任一节点点击按钮，可弹出对应维度的故障分析报告
- **趋势**：在该节点可查询日 / 周 / 月 / 自定义 4 档重要指标趋势

### 场景 2：自定义区域框选 + 弹窗 4 指标
- **工具**：矩形、圆形、多边形（任选 2 个即可）
- **弹窗字段**：
  1. 全阻物理站数
  2. 受影响的物理站数
  3. 资源数
  4. 退服占比
  5. RRC 最大连接数
- **区域范围可视化**：框选区域以高亮轮廓叠加在地图上

### 场景 3：街道级历史回溯
- **入口**：街道级界面
- **时间粒度**：日 / 周 / 月 / 自定义
- **交互**：时间轴拖动 → 地图上对应历史时间点的退服基站分布同步回放
- **数据形态**：按时序预切片（≤ 24 个时间点），保证拖动流畅

---

## 三、地图 & 数据呈现规则

| 项 | 规则 |
|---|---|
| 地图形态 | 静态图片（PNG），不实现地图拖动 / 缩放 |
| 地图层级 | 5 级（分公司 / 区 / 街道 / 社区 / 物理站），物理站下挂逻辑站 |
| 正常基站点位 | 保留约 100+ 个作为背景参照，浅色低饱和度 |
| 异常点位 | 仅展示告警 / 退服点，闪烁动画；按时序变换闪烁位置 |
| 空间围栏数据来源 | UI 手动绘制外轮廓（BigMap 排查后兜底方案），允许大轮廓近似 |
| 演示区域 | 石景山区 / 广宁街道 为重点演示对象 |
