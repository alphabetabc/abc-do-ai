（1）大屏支持地图呈现退服分布、物资、车辆、人员位置等多种图层呈现，支持按照分公司-行政区-街道乡镇-社区村庄-物理站-逻辑站逐级下钻数据统计呈现、支持查询不同空间维度的故障分析报告、支持查询不同时间粒度的重要指标趋势。

（2）大屏支持在地图上通过矩形、圆形、多边形自定义区域，查询该区域的全阻物理站/受影响的物理站、资源数、退服占比、RRC最大链接数，同时可以查看对应的区域范围

（3）大屏支持查询一段时间范围内的退服恢复趋势，并能够在地图上回溯出对应时间范围内的历史时间点的基站退服分布。
