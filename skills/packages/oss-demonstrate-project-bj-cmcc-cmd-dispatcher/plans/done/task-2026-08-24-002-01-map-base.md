## 二、技术决策

### 2.1 不引入 OpenLayers / fedx-gis / d3

-   地图形态 = 静态图片（见 `001-pm-output.md` §三"地图形态：静态图片（PNG），不实现地图拖动 / 缩放"）
-   OL 的 `view` / `projection` / `tile` / `VectorLayer` 等概念全是负担
-   `DrawFeature` 的 `drawType` 缺矩形；演示场景无需测距 / 框选查询
-   结论：**不引入 fedx-gis、不引入 d3、不引入任何新依赖**

### 2.2 渲染方案：SVG overlay

```
+--------------------------------------------------+
| <div cmd-dispatcher-map>                         |
|   +--------------------------------------------+ |
|   | <img src=...北京市.png>                    | |
|   +--------------------------------------------+ |
|   +--------------------------------------------+ |
|   | <svg viewBox="0 0 2880 1080">             | |
|   |   <rect/> <circle/> <polygon/> ...        | |
|   | </svg>                                     | |
|   +--------------------------------------------+ |
|   <MapHotZones />    <!-- z-index: 12 切层级 -->|
|   <MapToolbar />     <!-- z-index: 5 工具栏 -->  |
| </div>                                            |
+--------------------------------------------------+
```

-   SVG 与 React state 天然契合，shape 列表直接 `shapes.map(...)`
-   坐标统一用**设计稿像素**（与 task001 的 2880×1080 一致），**不引入投影**
-   热区用 DOM 节点（不放在 SVG 内），便于事件路由优先级

### 2.3 z-order 全栈

| 层               | 内容                          | z-index                                                                                            |
| ---------------- | ----------------------------- | -------------------------------------------------------------------------------------------------- |
| 顶层（覆盖所有） | `<Background>` 外框           | 10（task001 已设）                                                                                 |
| 中层（地图之上） | 热区 hot-zone                 | **12**（本次新增）                                                                                 |
| 中层（地图之上） | 工具栏                        | **5**（本次新增）                                                                                  |
| 中层（地图之上） | SVG overlay                   | 2                                                                                                  |
| 中层             | 地图 `<img>`                  | 1                                                                                                  |
| 底层             | 11 个浮层面板（task001 模块） | auto (=0)，但部分模块（如网络影响/基站退服）top 高于工具栏，需确保不与工具栏 `left: 2660` 区域重叠 |

### 2.4 工具栏位置

| 字段       | 值         | 说明                                           |
| ---------- | ---------- | ---------------------------------------------- |
| `position` | `absolute` | 浮在地图之上                                   |
| `left`     | `2660`     | 设计稿像素                                     |
| `top`      | `20`       | 设计稿像素                                     |
| `width`    | `200`      | 设计稿像素                                     |
| `height`   | `40`       | 设计稿像素                                     |
| `z-index`  | `5`        | 高于 SVG（z=2）和底图（z=1），低于热区（z=12） |

> 右下边界 `2660 + 200 = 2860` 在 2880 内（留 20px 边距）；底边 `20 + 40 = 60` 远早于右侧模块面板起始 top（84），**不重叠**。

### 4.4 `shape-renderer.tsx`

```tsx
import type { Shape } from './types';
import { DEFAULT_SHAPE_STYLE } from './types';

export const ShapeRenderer = ({ shape }: { shape: Shape }) => {
    const common = {
        stroke: DEFAULT_SHAPE_STYLE.stroke,
        strokeWidth: DEFAULT_SHAPE_STYLE.strokeWidth,
        fill: DEFAULT_SHAPE_STYLE.fill,
        pointerEvents: 'none', // 002-02 接入事件前先关掉，避免抢占
    };

    if (shape.type === 'rect') {
        return <rect {...common} x={shape.x} y={shape.y} width={shape.w} height={shape.h} />;
    }
    if (shape.type === 'circle') {
        return <circle {...common} cx={shape.cx} cy={shape.cy} r={shape.r} />;
    }
    const points = shape.points.map((p) => `${p.x},${p.y}`).join(' ');
    return <polygon {...common} points={points} />;
};
```

> `pointerEvents: 'none'` 是关键安全网：在交互未接入前，所有 SVG 元素不接收鼠标事件。

```tsx
                            border: active ? '1px solid rgba(0,255,255,0.4)' : 'none',
                            transition: 'background 0.2s',
                        }}
                        onMouseEnter={(e) => {

                        }}

                    />
                );
            })}
        </>
    );
};
```
