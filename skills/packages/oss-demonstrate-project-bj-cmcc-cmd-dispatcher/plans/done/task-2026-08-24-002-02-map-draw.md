## 二、技术决策

### 2.1 事件路由：SVG 容器统一接管

- mousedown / mousemove / mouseup / click / dblclick 绑定在 `<svg>` 根节点
- 通过 `activeTool` 决定事件处理分支：
  - `select`：click 命中检测
  - `rect` / `circle`：mousedown/move/up 拖拽
  - `polygon`：click 落点 + dblclick 收尾
- 命中检测：select 模式下，shape 元素 `pointerEvents: 'auto'`；其它模式 `none`，避免误选

### 2.2 坐标系：设计稿像素，不引入投影

- SVG `viewBox="0 0 2880 1080"`，`preserveAspectRatio="none"`
- 鼠标事件坐标转换：`getBoundingClientRect()` → 按比例映射到 2880×1080

```ts
const toDesignCoord = (e: React.MouseEvent, svg: SVGSVGElement) => {
    const rect = svg.getBoundingClientRect();
    return {
        x: ((e.clientX - rect.left) / rect.width) * 2880,
        y: ((e.clientY - rect.top) / rect.height) * 1080,
    };
};
```

### 2.3 DrawState 自管：组件内 useSetState，不入 store

- 临时绘制态（起点、当前点、polygon 顶点）由 `use-draw` hook 内部 `useSetState` 管理
- 仅在 mouseup / dblclick 收尾时调 `addShape` 落入 store
- 临时 shape 预览：hook 返回 `previewShape`，`<MapStage>` 额外渲染一层

### 2.4 选中态高亮

- `selectedShapeId` 命中后，`ShapeRenderer` 接收 `selected` prop，切换 stroke / strokeWidth
- select 模式下 shape `pointerEvents: 'auto'`，支持 click 命中

### 2.5 Delete 删除交互

> ⚠️ 用户已确认**不加快捷键**。本 task 的删除走交互：
> - 选中 shape 后，工具栏 area 或 shape 旁出现"删除"小按钮（具体位置见 §四落地方案）
> - 或：选中后右下角浮出确认按钮 `✕ 删除`
>
> 最终交互形态以 §四方案为准；若实现中发现更简洁的交互，可在 review 时调整。

### 3.2 `use-draw.ts`

```ts
import { useRef, useState } from 'react';
import { useCmdDispatcherStore } from '../../store';
import type { DrawState, Shape, Tool } from './types';

const genId = () => `s-${Date.now()}-${Math.random().toString(36).slice(2, 7)}`;

export const useDraw = (svgRef: React.RefObject<SVGSVGElement>) => {
    const activeTool   = useCmdDispatcherStore((s) => s.activeTool);
    const addShape     = useCmdDispatcherStore((s) => s.addShape);
    const setSelected  = useCmdDispatcherStore((s) => s.setSelected);
    const selectedId   = useCmdDispatcherStore((s) => s.selectedShapeId);
    const removeShape  = useCmdDispatcherStore((s) => s.removeShape);

    const [draw, setDraw] = useState<DrawState>({ kind: 'idle' });

    const toDesignCoord = (e: React.MouseEvent) => {
        const svg = svgRef.current!;
        const rect = svg.getBoundingClientRect();
        return {
            x: ((e.clientX - rect.left) / rect.width) * 2880,
            y: ((e.clientY - rect.top) / rect.height) * 1080,
        };
    };

    const onPointerDown = (e: React.MouseEvent) => {
        if (activeTool === 'select') return;
        const { x, y } = toDesignCoord(e);
        if (activeTool === 'rect' || activeTool === 'circle') {
            setDraw({ kind: `drawing-${activeTool}` as DrawState['kind'], startX: x, startY: y, currentX: x, currentY: y });
        }
        // polygon 不在 down 落点，在 click 落点
    };

    const onPointerMove = (e: React.MouseEvent) => {
        if (draw.kind === 'idle') return;
        const { x, y } = toDesignCoord(e);
        setDraw((d) => d.kind === 'idle' ? d : { ...d, currentX: x, currentY: y });
    };

    const onPointerUp = (e: React.MouseEvent) => {
        if (draw.kind === 'drawing-rect') {
            const w = Math.abs(draw.currentX - draw.startX);
            const h = Math.abs(draw.currentY - draw.startY);
            if (w > 2 && h > 2) {
                addShape({ id: genId(), type: 'rect',
                    x: Math.min(draw.startX, draw.currentX),
                    y: Math.min(draw.startY, draw.currentY),
                    w, h } as Shape);
            }
        } else if (draw.kind === 'drawing-circle') {
            const r = Math.hypot(draw.currentX - draw.startX, draw.currentY - draw.startY);
            if (r > 2) {
                addShape({ id: genId(), type: 'circle', cx: draw.startX, cy: draw.startY, r } as Shape);
            }
        }
        setDraw({ kind: 'idle' });
    };

    const onClick = (e: React.MouseEvent) => {
        if (activeTool !== 'polygon') return;
        const { x, y } = toDesignCoord(e);
        setDraw((d) => {
            if (d.kind === 'drawing-polygon') {
                return { ...d, points: [...d.points, { x, y }], currentX: x, currentY: y };
            }
            return { kind: 'drawing-polygon', points: [{ x, y }], currentX: x, currentY: y };
        });
    };

    const onDoubleClick = () => {
        if (draw.kind === 'drawing-polygon' && draw.points.length >= 3) {
            addShape({ id: genId(), type: 'polygon', points: draw.points } as Shape);
        }
        setDraw({ kind: 'idle' });
    };

    // 临时预览 shape
    let previewShape: Shape | null = null;
    if (draw.kind === 'drawing-rect') {
        previewShape = { id: 'preview', type: 'rect',
            x: Math.min(draw.startX, draw.currentX), y: Math.min(draw.startY, draw.currentY),
            w: Math.abs(draw.currentX - draw.startX), h: Math.abs(draw.currentY - draw.startY) };
    } else if (draw.kind === 'drawing-circle') {
        previewShape = { id: 'preview', type: 'circle', cx: draw.startX, cy: draw.startY,
            r: Math.hypot(draw.currentX - draw.startX, draw.currentY - draw.startY) };
    } else if (draw.kind === 'drawing-polygon') {
        previewShape = { id: 'preview', type: 'polygon', points: [...draw.points, { x: draw.currentX, y: draw.currentY }] };
    }

    return {
        svgProps: {
            onPointerDown, onPointerMove, onPointerUp, onClick, onDoubleClick,
        },
        previewShape,
        selectedId,
        selectShape: setSelected,
        deleteSelected: () => { if (selectedId) removeShape(selectedId); },
    };
};
```

> 具体实现细节（如 `kind` 类型断言、polygon 双击防误触）以最终代码为准；本片段为方案骨架。

### 3.3 `map-stage.tsx`（改）

```tsx
import { useRef } from 'react';
import { useDraw } from './use-draw';
import { ShapeRenderer } from './shape-renderer';

export const MapStage = () => {
    const shapes   = useCmdDispatcherStore((s) => s.shapes);
    const tool     = useCmdDispatcherStore((s) => s.activeTool);
    const svgRef   = useRef<SVGSVGElement>(null);
    const draw     = useDraw(svgRef);

    return (
        <div className="cmd-dispatcher-map">
            <img src="/static/images/bj-cmcc-cmd-dispatcher/北京市.png" alt="map" draggable={false}
                 style={{ width: '100%', height: '100%', display: 'block', pointerEvents: 'none' }} />
            <svg ref={svgRef} viewBox="0 0 2880 1080" preserveAspectRatio="none"
                 style={{ position: 'absolute', inset: 0, width: '100%', height: '100%', zIndex: 2,
                          // select 模式下整体可接收事件以做命中；其它模式由 hook 处理
                          pointerEvents: tool === 'select' ? 'auto' : 'auto' }}
                 {...draw.svgProps}>
                {shapes.map((s) => (
                    <ShapeRenderer key={s.id} shape={s}
                        selected={s.id === draw.selectedId}
                        interactive={tool === 'select'}
                        onSelect={() => draw.selectShape(s.id)} />
                ))}
                {draw.previewShape && <ShapeRenderer shape={draw.previewShape} preview />}
            </svg>
        </div>
    );
};
```

## 四、交互流程

### 4.1 rect / circle 拖拽

```
mousedown(activeTool=rect) → DrawState=drawing-rect, 预览渲染
mousemove                  → 预览实时更新
mouseup                    → addShape(最终 shape), DrawState=idle
```

### 4.2 polygon 落点

```
click(activeTool=polygon)  → points 追加, 预览渲染（含 currentX/Y 虚拟顶点）
click                      → 继续追加
dblclick                   → addShape(polygon), DrawState=idle
```

### 4.3 select 命中 + 删除

```
setTool(select)            → shape pointerEvents=auto
click(shape)               → setSelected(id), shape 高亮
click(🗑 按钮)             → removeShape(id), selectedId=null
```

## 六、验收标准

完成 review 后，需同时满足：

### 6.1 事件路由（3 条）

1. SVG 根据 `activeTool` 动态控制 `pointerEvents`，select 模式 shape 可命中，绘制模式不误选
2. 坐标转换准确：鼠标点击位置与 shape 落点在设计稿像素系下一致（误差 ≤ 2px）
3. 切换 `activeTool` 时不残留旧 DrawState（切工具自动 reset 为 idle）

### 6.2 rect / circle 绘制（3 条）

4. `activeTool=rect`：mousedown→move→up 创建一个 `<rect>`，尺寸 = 拖拽范围
5. `activeTool=circle`：mousedown 起点 = 圆心，拖拽距离 = 半径
6. 拖拽距离 ≤ 2px 不创建（防误触）

### 6.3 polygon 绘制（3 条）

7. `activeTool=polygon`：click 追加顶点，预览实时显示已落顶点 + 当前光标虚拟顶点
8. dblclick 收尾，顶点 ≥ 3 才 `addShape`
9. dblclick 后 DrawState 重置为 idle

### 6.4 select + 删除（3 条）

10. `activeTool=select`：click shape → `selectedShapeId` 更新，shape 高亮（stroke 变橙、strokeWidth=3）
11. 选中后工具栏出现"删除选中"按钮，点击 → `removeShape`，`selectedShapeId` 清空
12. 点击空白处（非 shape）→ `selectedShapeId` 清空

### 6.5 工程约束（4 条）

13. 不引入新依赖
14. 不修改 002-01 的 store 字段定义 / types / 热区 / 模块挂载（仅消费）
