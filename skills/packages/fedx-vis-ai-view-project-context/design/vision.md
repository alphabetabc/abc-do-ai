# vision.md

## 定位

组件物料站：解析外部业务项目源码，把其中可视化组件蒸馏为 spec / data-model / code / examples 四类产物，并提供检索与预览站点。

## 北极星

让外部项目中的组件以可检索、可预览、可直接复用的方式沉淀；新项目接入一个既有组件的边际成本趋近于零。

## 禁止清单

沿用根 `AGENTS.md` 全部禁令，另加：

- 文档与产物中禁用任何涉及人力替代的表述（如岗位替代类词汇）；只描述「组件蒸馏与复用」本身
- 物料产物保持自包含：不依赖站点代码、不跨模块 import、不引入共享 utils

## 假设

- 物料来源为外部业务项目源码，由人工驱动解析与提炼流程
- 模块数量会持续增长，站点性能依赖 manifest 唯一索引与按需加载
