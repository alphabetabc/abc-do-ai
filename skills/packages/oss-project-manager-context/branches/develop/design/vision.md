# vision.md

## 定位

电信 OSS 工程预约管理前端子应用。qiankun 微前端子应用，独立运行路由前缀 `/project`。覆盖工程预约的创建、审批、执行监控、资源检索与系统配置。

## 北极星

为电信 OSS 平台提供工程预约全流程管理能力：从预约创建（通用模板与十余个专题模板）、审批流转，到执行状态监控与工程资源联动。

## 背景与维护

原研发已离职，现由接手维护者继续维护。以保持稳定、渐进修复为主，不做大规模重构。

## 禁止清单

- 不新增状态管理库。
- 不升级 React 16、react-scripts 等大版本依赖。
- 不修改 sql/ 下 XML（后端维护）。
- 不读取、不要求提交 .env* 文件。

## 假设

- 后端接口与 sql/ 由后端域维护，本仓仅前端。
- 部署环境为 OSS 平台主应用内嵌（qiankun），独立运行仅用于开发调试。
