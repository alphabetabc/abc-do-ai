## 0. 分类口径

| 分类 | 定义（对应规则条款） |
| --- | --- |
| **前端可承接** | 规则「前端做」1~4：页面 UI / 表单 / 弹窗 / 列配置 / 前端导出 / 开关个性化 / 状态桥。含需后端配套新端点的页面功能（前端负责交互与调用层） |
| **纯后端** | 规则「后端做」：服务端接口、检测规则引擎、数据同步——本仓前端无页面，最多补 service 方法或完全不涉及 |
| **跨系统联调** | 规则「跨系统联调」：涉及主应用 / 其他系统（NCDP、专业工作台、全网调度）与本仓前端页面共同交付的链路 |
| **本仓不做** | 实现方为其他系统（NCDP、专业工作台、全网调度自身），本仓前端无交付物 |

> 附注列「联调依赖」标记前端可承接条目对外部系统数据/接口的依赖，供 002-03 风险评估。

## 5. 结论

- 需求主体中**前端交付面集中在 S2 割接单管理页面族（79 条）**，其余为后端引擎/服务端接口（34 条）与他系统实现（3+ 条）。

- D1~D3 均已裁决（2026-11-19 用户确认）：D1 免密跳转改判跨系统联调；D2/D3 确认所有页面能力在本仓完成。002-02 无遗留存疑，可进 002-03。
