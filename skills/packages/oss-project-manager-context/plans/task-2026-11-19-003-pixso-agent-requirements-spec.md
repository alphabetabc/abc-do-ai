## 目标（Goal）

设计并产出一份「给 Pixso 智能体的产出要求」文档：该智能体将访问 Pixso MCP 读取《网络操作预约模块优化提升》的原型稿，我们要用一份精确的指令让它**按我们的结构**提取原型信息，补齐 technical-analysis.md 中标注的缺口（45+ 字段表单布局、11/6 环节打点交互、详情 7 大块分区、六级审批动态行等「必须新写」部分的视觉与交互细节），直接作为 cutover-order 实施任务的输入。

**核心原则：本卡不碰 Pixso，只提要求。** 智能体能不能做到、怎么做到，是它和 MCP 的事；我们负责把「要什么、什么格式、什么算合格」说清楚。
