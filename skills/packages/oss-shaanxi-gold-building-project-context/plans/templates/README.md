# plans/templates/ · 任务与文档模板集中源

> **定位**：本目录存放 plans/ 下各文档的**空白模板**，供项目方复制后填充使用。
>
> **部署方式**：模板不部署到 IDE，由项目方按需复制到目标位置后改名 + 填正文。

---

## 模板清单

| 文件 | 用途 | 复制后命名 |
| --- | --- | --- |
| [`task-template.md`](./task-template.md) | **唯一官方**单任务卡（默认精简 + 可选强化块） | `TASK-YYYY-MM-DD-NNN-<slug>.md` |

> B5 **不**内置 SDD / 规格流水线等第二套任务概念。复杂任务展开 `task-template.md` 内「可选强化」即可。
>
> 项目若需要本地专用模板，自行新增 `task-template-<后缀>.md`（skill 升级不覆盖）；**不要**再从外项目粘贴整份流程手册进本目录默认清单。

---

## 何时新增

- 新增一种 `plans/` 下的文档类型（roadmap 子文档、handoff 模板等）且多项目复用
- 项目方本地专用后缀模板（不进 skill 默认必选面）

## 何时**不**该新增

- ❌ 一次性临时模板
- ❌ 已存在的同类模板（先复用 / 强化 `task-template.md`）
- ❌ 把外项目「全流程作战手册」当作 skill 默认第二套任务卡

---

> **关于引用一致性**：归档前必走清单见 `task-template.md` 内对应段，本 README 不重复。
