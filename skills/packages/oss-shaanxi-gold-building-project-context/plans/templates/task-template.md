## 引用一致性（归档前必走）

完成时**先**同步更新所有引用，**再**移动文件到 `done/<YYYY-MM>/`（详见 §3.6.1 R1）：

- [ ] `current-sprint.md` —— 移除该任务索引行
- [ ] `backlog.md` —— 若任务此前登记过，迁移到 `[REJECTED]` 或相应位置
- [ ] `plans/roadmap.md` / `plans/roadmap-YYYY-QN-*.md` —— 更新季度目标进度
- [ ] 外部任务系统（如适用）—— 同步状态

> 🚫 **禁止**：未完成全部引用更新前移动文件。
