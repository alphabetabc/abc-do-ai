# vision.md

## 定位

oss-pmmp 是 OSS 网元性能管理（Performance Management）前端子应用。为运维人员提供性能指标查询、规则配置、阈值管理、数据校验与报表的统一工作台。

## 北极星

运维人员能稳定、准确地完成网元性能数据的查询、配置与监控。

具体拆解：

- 查询：单机、区域、批量、类型、趋势多维查询，结果可图表/表格呈现。
- 配置：指标定义与分组、告警规则、阈值设定。
- 治理：数据校验规则、报表模板与样例。
- 监控：性能总览监控页一屏掌握关键指标。

## 禁止清单

- 不引入新框架、新状态管理、新 UI 库。
- 不动 config/webpack.config.js 等构建链，除非任务明确要求。
- 不主动升级大版本依赖。

## 假设

- 以 single-spa 微前端子应用形态部署为主；独立运行仅用于本地开发。
- 用户身份、系统信息由主应用注入（onGlobalStateChange），本应用不自建登录。
- 后端接口与数据格式由 OSS 平台侧约定，前端不做数据订正。
