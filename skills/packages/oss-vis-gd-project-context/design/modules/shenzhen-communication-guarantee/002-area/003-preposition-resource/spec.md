# 003-preposition-resource · 保障资源（spec）

## 职责

区域屏底部：呈现深圳的应急保障前置资源，类型及顺序固定——**保障人员、保障通信车、保障发电车**。widget 名「保障资源」（原「前置资源」）。

## 布局（设计稿）

- 尺寸：1668×280
- left 1086 / top 1680
- Panel 容器（含面板标题「保障资源」）

## 组件构成

- 共享资源统计卡组件（004 计划从信管局 support-resource 迁移，**当前代码尚未创建**，widget 为占位）
- 资源列表与顺序从 `share/presets.ts` 读取（区域屏配置：[人员, 通信车, 发电车]）

## 交互

静态展示，无联动。

## 边界

- 数量 0 时正常展示 0
