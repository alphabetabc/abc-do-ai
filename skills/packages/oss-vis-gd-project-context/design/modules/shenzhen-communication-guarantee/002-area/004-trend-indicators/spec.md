# 004-trend-indicators · 4G/5G 指标趋势（spec）

## 职责

区域屏左右对称两块（左 4G、右 5G），**一套组件两份配置**（`networkType: '4G' | '5G'`，`with-4g.tsx` / `with-5g.tsx` 包装）：

- RRC 连接数据（均值、最大值趋势）
- 接通率
- 无线平均利用率

## 布局（设计稿）

- 尺寸：926×1126，Panel 容器（标题「4G/5G 指标趋势」）
- 左（4G）：left 120 / top 840（紧接 4G 业务面板底部 216+600）
- 右（5G）：left 2800 / top 840

## 趋势规格

- 时间范围：当前时间往前 12 小时
- 粒度：2 小时一个点（共 7 个点，含当前）
- 指标：RRC 连接数均值、RRC 连接数最大值、接通率、无线平均利用率
