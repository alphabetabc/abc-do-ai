## 一、升级概述

本次升级针对网络覆盖中屏的GIS地图配置进行优化调整，主要涉及以下三个方面：

1. **地图视图参数优化** - 调整地图中心点坐标和缩放级别
2. **背景图布局调整** - 更新背景图尺寸和偏移位置
3. **图层配置完善** - 新增陕西全省区域的图层配置（含光缆流光动画）

---

## 二、修改内容详情

### 2.1 地图视图参数优化

**文件路径**：`public/environment-local.json#L101-104`

| 配置项    | 修改值                                     | 说明                               |
| --------- | ------------------------------------------ | ---------------------------------- |
| `center`  | `[108.63143417040855, 35.580495475851706]` | 地图中心点经纬度（陕西省地理中心） |
| `zoom`    | `7.28`                                     | 默认缩放级别                       |
| `minZoom` | `7.28`                                     | 最小缩放级别（锁定）               |
| `maxZoom` | `7.28`                                     | 最大缩放级别（锁定）               |

**修改目的**：

- 将地图中心点定位至陕西省地理中心位置
- 固定缩放级别，确保全省视图完整展示

---

### 2.2 背景图布局调整

**文件路径**：`public/environment-local.json#L122-125`

| 配置项         | 修改值  | 说明       |
| -------------- | ------- | ---------- |
| `bgSizeWidth`  | `805px` | 背景图宽度 |
| `bgSizeHeight` | `948px` | 背景图高度 |
| `bgPositionX`  | `15px`  | X轴偏移量  |
| `bgPositionY`  | `-17px` | Y轴偏移量  |

**修改目的**：

- 优化背景图尺寸以适配中屏显示区域
- 调整偏移位置使地图居中显示

## 四、升级步骤

### 步骤1：备份现有配置

```bash
cp public/environment-local.json public/environment-local.json.bak
```

### 步骤2：更新配置文件

将 `networkGisConfig` 节点下的相关配置替换为新版本配置。

### 步骤3：部署静态资源

将上述8个图片文件上传至服务器指定目录：

```
/static/images/center-network-coverage/map/
```

### 步骤4：验证升级

1. 重启前端服务
2. 登录系统进入网络覆盖中屏
3. 验证：
    - 地图显示完整的陕西省区域
    - 各网络图层正常叠加显示
    - 光缆流光动画正常播放
