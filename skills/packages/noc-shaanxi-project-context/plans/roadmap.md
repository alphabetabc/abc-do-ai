# 任务计划（plans）

后续任务通过在此目录建立 `task-yyyy-mm-dd-001-xxxx.md` 文件来记录任务内容。

## 命名规则

```
task-<yyyy-mm-dd>-<序号>-<任务名>.md
```

- `<yyyy-mm-dd>`：任务创建日期
- `<序号>`：当天内的三位递增序号（001、002、003 …）
- `<任务名>`：简短任务标识（英文小写，连字符分隔）

示例：`task-2026-09-08-001-merge-skills.md`

## 生命周期

1. 新任务创建在 `plans/` 根目录下
2. 任务完成后移动到 [done/](./done/) 归档
