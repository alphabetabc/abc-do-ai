# 下钻与派发逻辑总结

## 1. 概述

本文档总结项目中下钻（drill-down）和派发（dispatch）交互逻辑的实现方式。

- **下钻（Drill-down）**：用户点击某个数据项时，打开 Modal 或 Drawer 弹窗展示更详细的数据。
- **派发（Dispatch）**：用户点击时，将数据作为参数派发给其他组件或变量。

## 2. 核心常量定义

**文件位置**：`src/common/constants/interactions.ts`

| 常量名 | 值 | 说明 |
|--------|-----|------|
| `INTERACTION_TYPE_CELL` | `'Dispatch'` | 单元格级别派发 |
| `INTERACTION_TYPE_ROW` | `'RowDispatch'` | 行级别派发 |
| `INTERACTION_TYPE_MODAL` | `'Modal'` | 下钻打开 Modal |
| `INTERACTION_TYPE_DRAWER` | `'Drawer'` | 下钻打开 Drawer |
| `INTERACTION_TYPE_CheckBoxCELL` | `'CheckBoxDispatch'` | 复选框单元格派发 |

## 3. 核心 Hook

**文件位置**：`src/hooks/useInteractionHandle.ts`

### 3.1 drilldown 函数

处理下钻逻辑，检测是否配置了下钻事件并打开对应的 Modal/Drawer。

```typescript
const drilldown = (props, data, drilldownKey = 'drilldownEvent') => {
    const { interaction } = props;
    const definedDrilldownEvent = _.get(interaction, `defined.configurableEvent.${drilldownKey}`);

    if (definedDrilldownEvent?.show && drilldownEffect.includes(definedDrilldownEvent.effect) && !_.isEmpty(data)) {
        interaction.dispatch({
            data: [{
                fieldName: drilldownKey,
                state: { visible: true, ...data }
            }]
        });
        return true;
    }
    return false;
};
```

### 3.2 dispatchInteraction 函数

遍历 `interaction.defined` 中配置的所有派发字段，将数据派发给对应的变量。

```typescript
const dispatchInteraction = (props, data, options) => {
    const { interaction } = props;
    const actionsFields = Object.keys(interaction?.defined || {}).filter(d => d !== 'configurableEvent');

    const dispatchData = actionsFields.reduce((r, key) => {
        const definedKey = interaction?.defined?.[key];
        if (definedKey && interactionKeyValidator(definedKey)) {
            const dataKey = transformActionKeyToDataKey(key);
            if (_.isString(definedKey)) {
                r.push({ fieldName: definedKey, state: data?.[dataKey] });
            }
        }
        return r;
    }, []);

    if (dispatchData.length) {
        interaction.dispatch({ data: dispatchData });
    }
};
```

### 3.3 dispatchByEventMapping 函数

根据字段映射关系进行派发。

```typescript
const dispatchByEventMapping = (ownerProps, record, mapping) => {
    if (ownerProps.interaction) {
        const dispatchData = mapping
            .map(item => {
                if (!_.isEmpty(item) && item.dataIndex && item.dataIndex in record && item.action) {
                    return { fieldName: item.action, state: record[item.dataIndex] };
                }
                return false;
            })
            .filter(Boolean);
        if (!_.isEmpty(dispatchData)) {
            ownerProps.interaction.dispatch({ data: dispatchData });
        }
    }
};
```

## 4. Schema 配置结构

### 4.1 下钻配置 (configurableEvent)

**配置路径**：`configurableEvent.drilldownEvent`

| 字段 | 类型 | 说明 |
|------|------|------|
| `show` | boolean | 是否开启下钻 |
| `effect` | string | 事件效果：`Modal` 或 `Drawer` |
| `params` | string | URL 参数 |
| `drilldownItemFields` | string | 下钻时从数据项获取的字段列表，逗号分隔 |
| `title` | string | 弹窗标题（Drawer 专用） |
| `placement` | string | 位置：`top/bottom/left/right`（Drawer 专用） |
| `width/height` | number | 弹窗尺寸 |
| `mask` | boolean | 是否显示遮罩 |
| `closable` | boolean | 是否显示关闭按钮 |

### 4.2 动态事件配置 (dynamicEvents)

**配置路径**：`dynamicEvents[]`

支持的事件类型：

| effect 值 | 说明 |
|-----------|------|
| `RowDispatch` | 行单击派发参数 |
| `Dispatch` | 单元格单击派发参数 |
| `Modal` | 单元格单击弹出 Modal |
| `Drawer` | 单元格单击弹出 Drawer |
| `CheckBoxDispatch` | 复选框单击派发 |

## 5. 组件实现模式

### 5.1 基础派发模式

```typescript
const onClickHandler = (data) => {
    const actionsParams = Object.keys(interaction?.defined || {}).filter(Boolean);
    if (actionsParams.length > 0 && interaction?.dispatch) {
        interaction.dispatch({
            data: [{ fieldName: 'xxx', state: data }]
        });
    }
};
```

### 5.2 下钻+派发双重判断模式

```typescript
const onClickHandler = (record) => {
    const actionsParams = Object.keys(interaction?.defined || {}).filter(Boolean);
    if (actionsParams.length > 0 && interaction?.dispatch) {
        // 1. 优先处理下钻事件（Modal/Drawer）
        const drilldownEvent = interaction?.defined?.configurableEvent?.drilldownEvent;
        if (drilldownEvent?.show &&
            (drilldownEvent.effect === 'Modal' || drilldownEvent.effect === 'Drawer')) {
            interaction.dispatch({
                data: [{
                    fieldName: 'drilldownEvent',
                    state: { visible: true, ...record }
                }]
            });
            return;
        }

        // 2. 处理普通派发
        interaction.dispatch({
            data: [{ fieldName: 'clickEvent', state: record }]
        });
    }
};
```

### 5.3 动态事件处理模式

```typescript
const dynamicEvents = interaction?.defined?.dynamicEvents || [];
const eventOnCurKey = dynamicEvents.find(item => item.clickKey === columnKey);

if (eventOnCurKey) {
    if (eventOnCurKey.effect === 'Modal' || eventOnCurKey.effect === 'Drawer') {
        // 下钻

            data: [{
                fieldName: `${prefix}${eventOnCurKey.clickKey}`,
                state: { visible: true, ...record }
            }]
        });
    } else if (eventOnCurKey.effect === 'Dispatch') {
        // 派发
        interaction.dispatch({
            data: [{
                fieldName: `${prefix}${eventOnCurKey.clickKey}`,
                state: { ...record }
            }]
        });
    }
}
```

## 7. 交互流程图

```
用户点击
    │
    ▼
检查 interaction?.defined 是否配置
    │
    ├─ 否 → 无响应
    │
    └─ 是 → 检查 interaction?.dispatch 是否存在
                │
                ▼
            检查下钻事件 (drilldownEvent.show)
                │
                ├─ 是 + effect 为 Modal/Drawer
                │       │
                │       ▼
                │   dispatch({ fieldName: 'drilldownEvent', state: { visible: true, ...data } })
                │       │
                │       ▼
                │   打开 Modal/Drawer
                │
                └─ 否 → 检查动态事件 (dynamicEvents)
                            │
                            ▼
                        匹配 clickKey
                            │
                            ▼
                        dispatch({ fieldName: 'xxx', state: data })
```

### 8.3 指标组组件 - 指标点击派发

```typescript
const itemClickRef = (itemData, index) => {
    // 1. 直接派发参数
    const actionsParams = _.pick(interaction?.defined || {}, Object.keys(actionStateFormatter));
    const dispatchData = Object.entries(actionsParams).reduce((result, [key, fieldName]) => {
        if (fieldName) {
            return [...result, { fieldName, state: actionStateFormatter[key](itemData) }];
        }
        return result;
    }, []);

    if (dispatchData.length > 0) {
        interaction.dispatch({ data: dispatchData });
    }

    // 2. 旧配置下钻
    if (finalItemsSet[index]?.drilldown?.open) {
        interaction.dispatch({
            data: [{ fieldName: 'clickEvent', state: { visible: true, ...itemData } }]
        });
    }

    // 3. 新配置动态事件
    const eventOnCurKey = dynamicEvents.find(item =>
        item.clickKey?.split(',')?.includes(itemData.key)
    );
    if (eventOnCurKey?.effect === 'Modal/Drawer') {
        interaction.dispatch({
            data: [{ fieldName: `dynamicEvent_${eventOnCurKey.clickKey}`, state: { visible: true, ...itemData } }]
        });
    }
};
```

## 9. 总结

1. **核心机制**：通过 `interaction.dispatch()` 方法派发事件和数据，`interaction` 对象通过 props 传入组件。

2. **配置来源**：`interaction.defined` 对象包含所有交互配置，包括 `configurableEvent`（下钻配置）和 `dynamicEvents`（动态事件数组）。

3. **事件类型**：
   - 下钻事件：打开 Modal 或 Drawer，展示详细数据
   - 派发事件：将数据派发给指定的变量/字段

4. **优先级**：下钻事件 > 动态事件 > 普通派发

5. **数据传递**：通过 `dispatch` 方法的 `data` 参数传递 `{ fieldName, state }` 格式的数据。
