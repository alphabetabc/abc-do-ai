# OSS Visual Designer 项目架构说明书

## 1. 项目概述

**OSS Visual Designer** 是一个可视化大屏设计平台（Visual Designer），用于拖拽式创建和编辑数据可视化大屏。该项目基于 React 技术栈，支持多种可视化组件、实时数据绑定、以及丰富的交互功能。

### 1.1 项目特点

- **拖拽式设计**：提供可视化的拖拽编辑器，用户可以轻松组合各种可视化组件
- **实时预览**：支持所见即所得的预览效果
- **数据绑定**：支持多种数据源配置，包括 API、DPU、数据集等
- **组件化架构**：采用微前端架构设计，支持远程组件加载
- **多场景支持**：支持大屏设计器、场景监控、模板编辑等多种业务场景

## 9. 架构特点总结

### 9.1 组件化设计
- **物料系统**：支持远程组件加载，实现设计器与组件的解耦
- **字段组件**：每个设计单元都是"字段"，支持原子字段和组合字段

### 9.2 状态管理
- **Redux**：管理应用级状态（选中的组件、模式等）
- **Hox**：轻量级状态管理，用于业务状态（环境、登录信息等）
- **Context**：提供设计器上下文、作用域上下文

### 9.3 拖拽系统
- 基于 `react-dnd` 实现拖拽功能
- 支持图层排序、组件添加、位置调整
- 拖拽预览和实时位置计算

### 9.4 渲染引擎
- **Generator 模式**：通过配置动态生成组件
- **递归渲染**：支持嵌套组件的渲染
- **懒加载**：组件懒加载优化性能

### 9.5 数据流
- 支持多种数据源：API、DPU、数据集
- 实时数据流管理
- 数据缓存和节流控制
