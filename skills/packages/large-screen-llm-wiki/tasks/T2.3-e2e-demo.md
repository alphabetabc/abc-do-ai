# T2.3 端到端 Demo 闭环

> 计划窗口：11.27 – 12.04 | 依赖：T2.1 + T2.2 + T1.4 完成 | 状态：未开始

## 目标

在**空项目**（用户提供，路径待定）中打通完整链路：一句话 → Schema（LLM）→ 校验 → 适配层 → 渲染，Demo 为含 1 地图 + 2 图表 + 1 组联动的单屏，可现场演示。空项目从零跑通即为"换项目只重写适配层"的活证据。

## 输入

| 输入 | 位置 | 说明 |
| :--- | :--- | :--- |
| prompt 模板 + few-shot | `wiki/02-translation/` | 生成环节 |
| 校验器 + 重试策略 | `wiki/02-translation/` | 校验环节 |
| 适配层规范 + PoC | `wiki/03-adapter/` | 渲染环节（在空项目中按规范重写轻量适配） |
| 空项目 | 路径待用户提供 | Demo 落地容器，通用组件实现 |

> 注意：**不使用**本项目 `web/components/large-screen/` 渲染层——本任务在空项目中用通用组件（echarts 原生 + 简单布局）实现适配层，验证 Schema 不绑定任何组件库。

## 步骤

1. 确定虚构 Demo 场景（如"某市运行监控单屏"）：1 地图 + 2 图表（chart-bar + chart-line）+ 1 组联动（地图选中区域 → 图表过滤）
2. 在空项目实现轻量适配层：按 T1.4 规范，用通用组件实现本 Demo 所需的 3–4 个类型（map / chart-bar / chart-line）
3. 串链路：输入一句话 → LLM 生成 → 校验（失败自动重试）→ 适配 → 渲染
4. 演示准备：录屏或截图（虚构数据）
5. 收集翻译失败案例 ≥3 例（生成不对、校验拦截、纠错成功的各类型），入案例库
