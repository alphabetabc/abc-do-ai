# T2.1 翻译 prompt 模板设计

> 计划窗口：11.10 – 11.17 | 依赖：T1.4 完成（Schema v1 定稿） | 状态：未开始

## 目标

设计自然语言 → Schema 的 prompt 模板 v1：注入 Schema 约束、输出格式要求、few-shot 示例，可复用、非一次性脚本。

## 输入

| 输入 | 位置 | 说明 |
| :--- | :--- | :--- |
| Schema v1 完整定义 | `wiki/01-schema/schema-v1.ts` | 约束注入的来源 |
| widget 类型定义 | `wiki/01-schema/widget-types.md` | few-shot 示例要覆盖的类型 |
| 布局/联动/绑定规范 | `wiki/01-schema/layout-interaction-binding.md` | 示例需覆盖的结构 |

## 步骤

1. 设计模板骨架：系统指令（角色+任务）→ Schema 约束注入方式 → 输出格式要求（纯 JSON、无解释文字）→ few-shot 位置
2. 写 3–5 个 few-shot 示例：虚构场景（"某市运行监控大屏"类），从简单（2 个 widget）到复杂（含联动），输入用自然语言一句话到一段话
3. 用真实 LLM 跑 2–3 次冒烟测试，记录输出质量与常见偏差（如多余解释文字、字段编造）
4. 根据偏差迭代模板 v1.1，偏差记录留给 T2.2 / T3.2

## 输出

| 产物 | 落盘位置 | 内容要求 |
| :--- | :--- | :--- |
| prompt 模板 v1 | `wiki/02-translation/prompt-template.md` | 模板全文 + 各段设计说明（等级 A） |
| few-shot 示例集 | `wiki/02-translation/few-shots.md` | 3–5 组 输入→Schema 输出 对（等级 A） |
| 冒烟测试记录 | `wiki/02-translation/smoke-test-notes.md` | 测试输入、输出偏差、迭代结论 |

## 验收

- [ ] 模板可脱离本项目直接使用（零项目概念，grep 自查）
- [ ] few-shot 覆盖：≥4 种 widget 类型、≥1 组联动、简单/复杂各至少 1 例
- [ ] 冒烟测试有真实输出记录（不是纸面设计）
- [ ] 素材进第四次周同步（~11.18，含失败案例）
