# T3.3 复用性验证与收尾（SOP 终稿 + skill 收口）

> 计划窗口：12.24 – 12.31 | 依赖：T3.2 完成（全链路前置任务均完成） | 状态：未开始

## 目标

产出大屏生成 skill / SOP 终稿（含换项目/换组件库的迁移指引），并收口整个 skill 工作区。这是年底交付物的最终形态：**交付物统一放空项目**（skill / SOP / Demo 汇总为独立可跑的资产包）。

## 输入

| 输入 | 位置 | 说明 |
| :--- | :--- | :--- |
| 全部 wiki 产出 | `wiki/01-schema/` `02-translation/` `03-adapter/` `04-cases/` | SOP 的引用源 |
| 适配层规范与 PoC | `wiki/03-adapter/` | "换项目只重写适配层"的验证依据 |
| 使用边界说明 | `wiki/04-cases/scope-and-limits.md` | SOP 里的适用范围声明 |

## 步骤

1. 写 SOP：从零复用的完整步骤——引入 Schema 规范 → 接入翻译模板与校验器 → 重写适配层（含工作量估计）→ 跑通第一个 Demo
2. 复用性验证：用 SOP 走一遍"模拟换组件库"的推演（或最小实操：换 1 个组件的映射），确认步骤可执行
3. skill 收口：更新 `SKILL.md` 文件索引、`wiki/overview.md` 状态；全部文档补齐"可带走等级"标注
4. 死链与红线终查

## 输出

| 产物 | 落盘位置 | 内容要求 |
| :--- | :--- | :--- |
| SOP 终稿 | `wiki/05-sop/reuse-guide.md` | 迁移步骤 + 工作量口径 + 适用范围（等级 A） |
| 复用验证记录 | `wiki/05-sop/reuse-check.md` | 推演/实操过程与结论 |
| skill 收口 | 更新 `../SKILL.md`、`../wiki/overview.md` | 索引完整、状态更新 |

## 验收

- [ ] SOP 按 step-by-step 可执行，无"参考代码"式的模糊步骤
- [ ] 复用验证有实际结论（哪怕结论是"某步骤成本比预想高"）
- [ ] 全部 wiki 文档有可带走等级标注，无死链
- [ ] 红线终查通过：对外交付版零项目名 / 业务概念 / 真实数据泄漏
- [ ] 年底交付：向领导提交的最终材料以本任务产出为核心（skill / SOP，而非代码清单）

## 完成后动作
