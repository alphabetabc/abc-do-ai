# T3.1 生成链路边界扩展（场景模板）

> 计划窗口：12.01 – 12.15 | 依赖：T2.3 完成 | 状态：未开始

## 目标

补充典型场景模板（应急大屏 / 指挥中心类布局模式），让生成链路覆盖常见大屏形态；以模板沉淀为主，不追全量。

## 输入

| 输入 | 位置 | 说明 |
| :--- | :--- | :--- |
| Schema v1 | `wiki/01-schema/` | 模板挂载的结构基础 |
| Demo 案例与失败案例 | `wiki/04-cases/` | 已验证的生成边界 |
| 页面反查记录 | `wiki/03-adapter/inventory/usage-audit.md` | 真实页面的布局模式（脱敏后归纳） |

## 步骤

1. 归纳 2–3 类典型布局模式（如：地图主导型 / 指标看板型 / 三栏指挥型），每类描述：布局骨架、常见 widget 组合、典型联动形态
2. 每类做成可复用模板：预填布局结构 + 占位 widget（Schema 片段），生成时可整块引用
3. 为每类补 1 个 few-shot 示例（自然语言 → 基于模板的 Schema）
4. 用模板跑 1 次生成验证，记录效果

## 输出

| 产物 | 落盘位置 | 内容要求 |
| :--- | :--- | :--- |
| 布局模式与模板 | `wiki/01-schema/layout-patterns.md` | 2–3 类模式定义 + Schema 模板片段（等级 A） |
| 场景 few-shot | 追加到 `wiki/02-translation/few-shots.md` | 每类模式 1 例 |

## 验收

- [ ] 2–3 类布局模式均可用模板表达并生成成功至少 1 次
- [ ] 模板片段可直接拼入 Schema（不是纸面描述）
- [ ] 通用性自查通过
