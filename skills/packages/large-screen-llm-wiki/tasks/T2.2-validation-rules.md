# T2.2 校验与纠错规则

> 计划窗口：11.17 – 11.24 | 依赖：T2.1 完成 | 状态：未开始

## 目标

实现 Schema 校验器（结构合法性 / 枚举值 / 布局越界）+ 生成失败自动重试策略，形成通用层规则资产。

## 输入

| 输入 | 位置 | 说明 |
| :--- | :--- | :--- |
| Schema v1 完整定义 | `wiki/01-schema/schema-v1.ts` | 校验规则的依据 |
| prompt 模板 v1 | `wiki/02-translation/prompt-template.md` | 纠错回喂的载体 |
| 冒烟测试记录 | `wiki/02-translation/smoke-test-notes.md` | 已知偏差类型 = 首批校验点 |
| 布局/联动规范 | `wiki/01-schema/layout-interaction-binding.md` | 越界与联动引用合法性规则来源 |

## 步骤

1. 定义校验规则清单：结构合法性（必选字段/类型）、枚举值（widget 类型、来源类型等）、布局越界、联动引用合法性（订阅的派发字段必须存在）
2. 实现校验器：Node 脚本，仅内置依赖（fs/path），CLI 可用，输出结构化错误（错误码 + 位置 + 说明）
3. 定义重试策略：校验错误 → 组装纠错 prompt（错误信息回喂）→ 重新生成 → 最多 N 次（建议 3）
4. 用冒烟测试的失败输出做回归用例

## 输出

| 产物 | 落盘位置 | 内容要求 |
| :--- | :--- | :--- |
| 校验规则文档 | `wiki/02-translation/validation-rules.md` | 规则清单 + 错误码表 + 重试策略（等级 A） |
| 校验器脚本 | `wiki/02-translation/scripts/validate-schema.js` | 可执行、幂等、显式退出码 |
| 纠错 prompt 片段 | 并入 prompt-template.md 或独立 `retry-prompt.md` | 错误信息注入的写法（等级 A） |

## 验收

- [ ] 校验器对合法 Schema 通过、对三类非法输入（结构/枚举/越界）各能报出结构化错误
- [ ] 回归用例全部通过（冒烟测试的失败输出被拦截）
- [ ] 脚本符合项目脚本规范（Node 内置依赖、process.exit、进度输出）
- [ ] 规则文档零项目概念泄漏
